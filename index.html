Aim To create a simple HTML webpage that demonstrates the use of basic CSS selectors such as Universal Selector, Element Selector, ID Selector, Class Selector, and Grouping Selector for styling HTML elements. Procedure 1. Open a text editor such as Notepad or Visual Studio Code. 2. Create a new HTML file and save it as basic_selectors.html. 3. Write the basic HTML structure using <!DOCTYPE html>, <html>, <head>, and <body> tags. 4. Add an internal <style> section inside the <head> tag. 5. Define different CSS selectors:  Universal Selector (*)  Element Selector (h1)  ID Selector (#heading)  Class Selector (.info)  Grouping Selector (h2, p) 6. Add HTML elements such as headings and paragraphs in the <body> section. 7. Apply the CSS selectors to the corresponding HTML elements. 8. Save the file and open it in a web browser. 9. Observe how each selector applies different styles to the HTML elements. Code: <!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <title>Basic CSS Selectors</title> <style> /* Universal Selector */ * { font-family: Arial, sans-serif; } /* Element Selector */ h1 { color: darkblue; text-align: center; } /* ID Selector */ #heading { color: red; } /* Class Selector */ .info { color: green; font-size: 18px; } /* Grouping Selector */ h2, p { margin: 10px; } </style> </head> <body> <h1 id="heading">Basic CSS Selectors</h1> <h2>Element Selector Example</h2> <p class="info"> This paragraph uses the <strong>class selector</strong>. </p> <p> This paragraph is styled using the <strong>grouping selector</strong>. </p> </body> </html> Result: The HTML page is created successfully, and the basic CSS selectors are applied correctly to style the webpage.
